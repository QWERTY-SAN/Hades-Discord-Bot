# Data layout

`data/aether_gazer/` contains the local, source-aware Aether Gazer knowledge layer.

- `game_knowledge.json` — world, systems, resources, endgame, events, lifecycle, scans, and auxiliary systems.
- `terminology.json` — stable terms used by the scope and context matcher.
- `source_policy.json` — rules for distinguishing canon, dated gameplay data, and uncertainty.
- `sources.json` — reference URLs and source metadata.
- `characters/` — Hades and character-specific reference data.

Do not treat this data as a live connection to the game. Version-sensitive details are labeled accordingly.
